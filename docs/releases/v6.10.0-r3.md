## Summary

This release fixes three issues the first real tag run exposed in the tag-driven pipeline: published contents are now verified by unpacking both tarballs and diffing file by file (the sha1 check was both tautological and defeated by the pre-publish E404 negative cache); the publish probe uses `--prefer-online` so a re-run cannot replay that cache and hit 409; and the on-`main` gate now compares the checked-out tag commit instead of `GITHUB_SHA`, which under `workflow_dispatch` was main itself and always reported `identical`. README, AGENTS and release notes no longer attribute post-r2 changes to r2. No runtime behaviour change.

## Changes

- #90 Verify the published artifact by unpacking and diffing file by file, proving the installed files match the tag tree.
- #91 Probe with `--prefer-online` so a re-run does not replay the pre-publish E404 cache; correct the README version rows and fallback wording.
- #92 Compare the checked-out commit in the on-`main` gate so dispatch re-runs no longer pass vacuously; document that a tag may legitimately be `behind`; drop an unused step output.
