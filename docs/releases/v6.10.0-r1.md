## Summary

This release closes out the system-interpreter probe and install chain and completes the personal template library work across sync, verification and packaging. Runtime behaviour changes: `ppt_master_check_env` falls back to `python` when `python3` is missing or below 3.10, naming the command actually hit in a new top-level `pythonCommand` payload field; `ppt_master_setup_deps` resolves its system installer as `pip3` → the resolved interpreter's `-m pip` → `pip`, accepting `pip3` only when its self-reported Python minor matches the interpreter `check_env`/the guard uses and it does not declare Python 2. The personal template library that lives inside the plugin package since v6.10.0 is no longer silently deleted on upgrade and never ships in the published package.
